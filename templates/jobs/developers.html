What you get for every role

  • Verification: status, method and when we last checked the employer's board
  • Eligible countries and remote scope (worldwide, specific countries, unspecified)
  • Pay range, currency and period, normalized
  • Job type and experience level
  • Organization: homepage, careers page, logo
  • Posted, last updated and closing dates
  • Listing URL and apply URL
  • Commercial tier: skills, must-haves with source quotes, full text of employer-posted roles

Most listings are gathered from employers' own boards and other sources, so the API carries a short excerpt of the description plus the link, never the full text, except for roles employers post directly on Remote Impact. Our added data (verification, eligibility, pay, must-haves, organization records) is what you're licensing.

REST API

Base URL {{ site }}/api/v1/. JSON, CORS enabled, no key needed to start. Full parameter list in the OpenAPI spec.

Search open roles

GET {{ api_url }}?q=monitoring+evaluation&country=Kenya&level=mid&posted_since=14d

Filters: q, area, country, remote_scope=worldwide, job_type, level, min_salary, posted_since (ISO date or 7d), organization, source=employer_posted, page, limit.

One role, an organization, the areas

GET {{ site }}/api/v1/jobs/<slug>/
GET {{ site }}/api/v1/organizations/<slug>/
GET {{ site }}/api/v1/areas/

A closed role answers 404 with "status": "closed", so you can retire it on your side.

MCP server for AI assistants

Claude, ChatGPT, Cursor and other assistants that support the Model Context Protocol can call the same data as tools: search_jobs, get_job, list_areas, get_organization. Streamable HTTP, no sign-up needed to try it; add a key for higher limits.

Endpoint

{{ mcp_url }}

Claude Code

claude mcp add --transport http remote-impact {{ mcp_url }}
# with a key:
claude mcp add --transport http remote-impact {{ mcp_url }} \
  --header "Authorization: Bearer ri_..."

Other clients

Add a remote MCP server (HTTP transport) with the endpoint above. In Claude Desktop and ChatGPT this is under connectors or custom MCP servers; in Cursor it's an mcp.json entry with "url": "{{ mcp_url }}". Then ask: "Find remote climate roles I can apply to from Kenya, mid-level, paying at least $40k."

Read-only, no sessions. Every result carries the listing URL so the assistant can cite it.

Terms, in plain words

  • Attribution: show "via Remote Impact" and link to the listing URL whenever you display a role.
  • No republishing of descriptions: excerpts and our structured fields only. Full text belongs to the employer; the free tier is for non-commercial use.
  • Keep it current: re-fetch at least daily and drop roles that answer 404 or whose verification status is not open. Don't keep showing closed jobs.
  • Limits: stay within your tier; keys that scrape or share access can be revoked. We may change limits with notice.
  • No personal data: the API contains job and organization records only.
  • Questions, bulk needs or research partnerships: hello@remoteimpact.org.
